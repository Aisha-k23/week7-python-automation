# Python Data Automation

## Overview

This project is a Python automation script that reads a dataset and automatically generates summary statistics.

The script uses the Titanic dataset and calculates:

- Total number of passengers
- Average fare
- Female survival rate
- Male survival rate

## Skills Demonstrated

- Python
- Pandas
- Reading CSV files
- Command-line arguments
- Data automation

## How to Run

Run the following command:

python titanic_summary.py titanic.txt

## Files

- `titanic_summary.py` - Python automation script
- `titanic.txt` - Titanic dataset

## What I Learned

This project helped me practise creating a Python script that automatically processes a dataset and produces useful summary information.
